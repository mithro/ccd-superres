# Diagrams

Every figure in this documentation that is not a flow chart is generated by
one script, so the figures can be regenerated when the model changes:

```
python docs/diagrams/make_diagrams.py
```

The script writes each figure as SVG (used in these pages) and PNG. Flow
charts are written as Mermaid blocks inside the pages themselves.

| Figure | Shows | Source of the numbers |
|---|---|---|
| `scan-geometry` | Top view of the tilted sensor, scan direction and pixel tracks | Illustrative |
| `cross-section` | Side view of sensor, gap and surface | Illustrative |
| `sampling-pattern` | Sample centres from one pixel and from a sensor row | Computed from the geometry |
| `sensor-stack` | Layers on the sensor face, before and after removing the microlenses | Layer order from the cited cross-section study; not to scale |
| `resolution-budget` | Contrast passed by the gap and by the pixel area | Analytic model |
| `gap-requirement` | Smallest recoverable period against gap | Analytic model |
| `target-100nm` | Contrast of 100 nm lines and spaces against gap, matt and mirror-like surfaces | Analytic model |
| `two-regimes` | Side views of the near-field and far-field slanted-light arrangements | Illustrative, not to scale |
| `motion-blur` | Where a reading collects light for three exposure patterns, and what each lets through | Analytic model |
| `exposure-comparison` | Smallest recoverable period for five exposure options under two light conditions | Analytic model |
| `readout-timing` | When each row is exposed and read for three readout schemes | Illustrative timing |
| `array-angles` | Directions collected by the array from one point at a 1 mm gap | Sensor dimensions |
| `plan-status` | Plan items by phase and state | Read from `docs/plan.md` |
| `samples-vs-resolution` | Smallest recoverable period against sample count | Analytic model |
| `subpixel-coverage` | Where the samples of one point fall inside a pixel | Scan calculator |
| `level-validity` | Range where each simulation level is valid | Indicative, to be replaced by cross-check results |
| `level1-reconstruction` | True bars, one raw frame and three reconstructions | Level 1 simulator, seed 1 |
| `level1-crosscheck` | Level 1 blur and noise against the level 0 formulas | Level 1 simulator and analytic model |

## Calibration and test figures

The figures on the [calibration and test methods](calibration-and-test.md)
page come from a third script. It also runs the small rehearsal simulations
and prints the numbers quoted on that page:

```
python docs/diagrams/make_calibration_diagrams.py
```

| Figure | Shows | Source of the numbers |
|---|---|---|
| `calib-map` | Where each instrument number comes from, for eight families of approach | Summary of section 2 |
| `calib-tolerances` | How well each quantity must be known against the period being resolved | Contrast-loss formula |
| `calib-anchors` | The three quantities the scan cannot fix by itself | Illustrative |
| `calib-identifiability` | Which unknowns the data can separate, in a toy scan | One-dimensional calculation |
| `calib-coherence` | Width of the strip where fringes survive against the laser's spread of wavelengths | Two-beam interference formula |
| `calib-photon-transfer` | Rehearsal of the photon transfer measurement with hidden gain and read noise | Simulated pixel readings |
| `calib-fringe-response` | Pixel contrast for 213 nm fringes for four assumed pixel edges | Analytic pixel model |
| `calib-beat` | Fine fringes read through the pixel grid as a broad beat pattern | One-dimensional calculation |
| `calib-timing` | Rehearsal of the strobed-light check of the row time | Simulated rolling-shutter frame |
| `calib-measures` | Bar contrast and edge response measured on toy reconstructions | One-dimensional calculation |
| `calib-frc-how` | How Fourier ring correlation is computed, step by step | Two-dimensional toy calculation |
| `calib-targets` | Periods offered by each reference sample against the stage targets | Published dimensions, cited on the page |
| `calib-frc-demo` | A prior that invents detail passes a split-data test and fails against the truth | Two-dimensional toy calculation |
| `calib-heldout` | Four ways of holding data back from the fit | Illustrative |
| `calib-scenes` | The ten benchmark scenes, drawn schematically | Generated scenes |
